# Проект: Каталог идей для Python-проектов (project_ideas)

## Описание
Программа хранит список идей для проектов на Python, выводит их на экран в удобном виде и позволяет пользователю добавлять новые идеи через консоль.

## Инструкция по запуску
1. Убедитесь, что у вас установлен Python.
2. Откройте папку с проектом в среде разработки (например, PyCharm).
3. Запустите файл `main.py`.
