# API каталога роботов-исследователей

Этот проект представляет собой REST API на FastAPI для хранения информации о роботах, исследующих космические объекты.

## Установка и запуск

1. Установите зависимости:
   ```bash
   pip install -r requirements.txt
```

2. Запустите сервер:
   ```bash
   uvicorn main:app --reload
   ```
3. Документация доступна по адресу: http://127.0.0.1:8000/docs
