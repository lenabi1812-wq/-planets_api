# Каталог космических миссий

Консольное приложение на Python для просмотра списка космических миссий и поиска их по направлению.

## Возможности
- Вывод полного списка миссий.
- Поиск миссий по заданному направлению (например, "Луна", "Марс").
- Сообщение об отсутствии результатов поиска.

## Структура проекта
| Файл | Описание |
| :--- | :--- |
| `main.py` | Основной файл для запуска программы и взаимодействия с пользователем. |
| `missions.py` | Содержит данные о миссиях и функции для работы с ними. |
| `README.md` | Документация проекта. |

## Инструкция запуска
1. Убедитесь, что у вас установлен Python 3.
2. Скачайте проект.
3. В терминале перейдите в папку проекта.
4. Запустите команду:
   ```bash
   python main.py
